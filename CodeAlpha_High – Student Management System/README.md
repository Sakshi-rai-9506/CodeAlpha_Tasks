# 🎓 Student Management System in C

## 📖 Overview

The **Student Management System** is a menu-driven application developed using **C Programming**, **Structures**, and **File Handling**. It allows users to manage student records efficiently by storing information permanently in a file.

The application supports creating, searching, updating, deleting, and displaying student records, making it a practical example of file-based data management in C.

---

## 🎯 Objectives

- Store student records permanently.
- Perform CRUD operations.
- Learn file handling techniques.
- Understand structures in C.
- Build a menu-driven application.

---

## ✨ Features

- ➕ Add Student
- 🔍 Search Student
- ✏️ Update Student
- ❌ Delete Student
- 📋 Display Student Records
- 💾 Permanent Data Storage
