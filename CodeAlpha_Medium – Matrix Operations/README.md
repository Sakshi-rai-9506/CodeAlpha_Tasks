# 🔢 Matrix Operations in C

## 📖 Overview

The **Matrix Operations** project is a console-based C application that performs common mathematical operations on matrices. The program supports **Matrix Addition, Matrix Multiplication, and Matrix Transpose** using functions and two-dimensional arrays.

This project demonstrates modular programming techniques and improves understanding of array manipulation and matrix calculations.

---

## 🎯 Objectives

- Perform matrix addition.
- Perform matrix multiplication.
- Find the transpose of a matrix.
- Use functions for modular programming.
- Practice working with two-dimensional arrays.
