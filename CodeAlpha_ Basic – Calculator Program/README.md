# 🧮 Basic Calculator in C

## 📖 Overview

The **Basic Calculator** is a console-based application developed using the **C Programming Language**. It performs the four fundamental arithmetic operations: **Addition, Subtraction, Multiplication, and Division**. The program provides a simple menu-driven interface where users can choose an operation using a **switch-case** statement.

This project was developed to understand the fundamentals of C programming, including user input/output, decision-making statements, arithmetic operators, and basic program structure.

---

## 🎯 Objectives

- Build a menu-driven calculator application.
- Implement arithmetic operations using the `switch-case` statement.
- Handle invalid user input effectively.
- Prevent division-by-zero errors.
- Improve logical thinking and problem-solving skills.
