# 🏦 Bank Account Management System in C

## 📖 Overview

The **Bank Account Management System** is a mini banking application developed in **C Programming** using **Structures**, **Functions**, and **File Handling**. The application allows users to create bank accounts, deposit money, withdraw funds, and check account balances while maintaining records permanently.

This project demonstrates the implementation of basic banking operations using file-based data storage.

---

## 🎯 Objectives

- Create bank accounts.
- Deposit money.
- Withdraw money.
- Check account balance.
- Store account information permanently.
